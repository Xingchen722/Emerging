🚫 Undefined Message Fixes

Fixed the "undefined" messages that appeared after function calls.

Root Causes Fixed:

  • Duplicate Event Listeners: Fixed generic pill click listener that was conflicting with onclick handlers
  • Response Validation: Added validation to ensure responses are not undefined before displaying
  • Fallback Messages: Added proper fallback messages when functions fail
  • Event Handler Separation: Only pills with data-q attribute get generic listeners

🎯 Technical Details

CSS Changes:

  • .chat-body { max-height: 400px; } - Reduced chat height
  • .chat-quick { max-height: 120px; overflow-y: auto; } - Scrollable button area
  • .pill { padding: 6px 10px; font-size: 12px; white-space: nowrap; } - Compact buttons

JavaScript Changes:

  • document.querySelectorAll('.pill[data-q]') - Only listen to data-q pills
  • if(response && response !== 'undefined') - Validate responses
  • addBubble(fallbackMessage, 'bot') - Fallback for failed responses
